# prompts

example `CLAUDE.md` files and system prompts. a `CLAUDE.md` is a file Claude Code reads at the start of every session, like a standing brief for ur agent.

- put one in a project root (`./CLAUDE.md`) for project rules
- put one in `~/.claude/CLAUDE.md` for rules that follow u everywhere

add urs: one file per prompt, plus a line in the table below. same rules as skills: nothing private.

| file | what it's for |
|---|---|
| [personal-CLAUDE.md](personal-CLAUDE.md) | a starter `~/.claude/CLAUDE.md`: how u like to work, ask before risky stuff, verify before saying done |
